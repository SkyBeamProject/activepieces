# Overview

Activepieces is an open-source, type-safe automation platform — a self-hostable alternative to Zapier. Workflows ("flows") are built in a visual drag-and-drop editor with support for branches and loops, and integrations ("pieces") are written in TypeScript.

Highlights:

- 80+ integrations (Google Sheets, OpenAI, Discord, RSS, etc.) and a growing catalog [published to npm](https://www.npmjs.com/search?q=%40activepieces).
- A TypeScript framework for building custom pieces.
- Community Edition under [MIT](LICENSE); enterprise features under a separate [commercial license](packages/ee/LICENSE).

See [`README.md`](README.md) or the [official documentation](https://www.activepieces.com/docs) for installation, contribution guides, and the full feature list.
